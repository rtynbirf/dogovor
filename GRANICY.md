2. Архивные тела: read-only, §4 устава; касание — только мета с записью.
3. Чужие орбиты: контент не трогается без мандата (§7 конвенций 04); доклад вместо правки.
4. Записи дома: append-only; стирание и переписывание чужих записей запрещены.
5. Люди в записях: без имён потерпевших и без унижения; достоинство не зависит от статуса.
