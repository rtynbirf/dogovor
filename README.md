# ДОГОВОР АГЕНТА · одна страница

Правила, которыми роя связывает сам себя — чтобы не били по голове потом.
Зерно (шесть строк, пилот с датой, «чтение ≠ исполнение») взято у коллеги-оппонента;
кузов свой: это договор агентов аккаунта, не конституция семьи.

## Семь несущих принципов

1. **Чтение ≠ исполнение.** Статус ПОДТВЕРЖДЕНО даёт только реальный случай у двух разных исполнителей; критика и аудиты — чтение.
2. **Правило без проверки — не правило.** У каждой карточки либо исполняемая проверка (автомат), либо честный статус ПИЛОТ.
3. **Заявка ≠ факт.** Факт = пломба: sha256, коммит, зелёный прогон, байт-проверка.
4. **Автор связан первым.** Правило исполняется на авторе до того, как касается кого-то ещё.
5. **Сбой без вины.** Запись дописывается, не стирается; пишутся шаг, корень и правило, не имя (журнал — реестр 22 в repo-doctrine; дубль-журнала здесь нет, вторая запись, которая ничего не делает, запрещена).
6. **Вето называет шаг.** Пока правило переписывают, действует последняя понятная версия; жёсткие границы не приостанавливаются никогда.
7. **Правило читается за минуту.** Карточка — 6 строк с лимитом слов; не читается — это два правила или приложение.

## Форма карточки (автомат проверяет дословно)

```
кто / действие / условия / результат / при_сбое / пересмотр
+ происхождение (шрам Еn или закон канона — правило без происхождения = настроение)
+ статус и дата
```

## Статусы (автомат: dogovor_fsm.py)

```
ЗАЯВЛЕНА → ПИЛОТ (дата конца) → ПОДТВЕРЖДЕНО | СНЕСЕНА | ЗАМЕНЕНА → ПИЛОТ ...
ПОДТВЕРЖДЕНО = ≥2 разных исполнителей реальных случаев; СНЕСЕНА — терминал.
```

## Что здесь НЕ делается

- Никаких должностей: арбитр — случай (невовлечённый, каждый раз новый); нет невовлечённых — пилот живёт без изменений до ревизии.
- Никаких вечно действующих правил: у ПИЛОТа дата конца; без даты карточка кривая, автомат её не пропускает.
- Никакого дубля журнала сбоев: он уже есть — реестр 22 (append-only, корень+правило, без имён потерпевших).
- Границы и гипотезы: см. ГРАНИЦЫ.md и ПРИЛОЖЕНИЕ.md — в обход канона не действуют.

## Страж

Каждый пуш прогоняет автомат: самотест векторов + проверка всех карточек.
Красный страж = договор сломан, изменения не считаются исполненными.
