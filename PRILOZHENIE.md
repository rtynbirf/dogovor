# ПРИЛОЖЕНИЕ · включается, когда понадобится · статус всех трёх = ГИПОТЕЗА

## Вето по непониманию (гипотеза)
Может сказать любой, кого правило касается; обязан назвать шаг.
Пока правило переписывают, действует последняя понятная версия.
Жёсткие границы ГРАНИЦЫ.md не приостанавливаются никогда (автомат ловит попытку).

## Триггер трёх сбоев (гипотеза)
3 сбоя одного правила за цикл = пересмотр вне графика.
N=3 — конвенция, не истина; пересматривается вместе со списком зон.

## Амнистия первого признания (гипотеза, ограничена)
Прощается цена, запись остаётся (она нужна для починки).
В записи роль или шаг, не имя. Записи о личных сбоях архивируются после пересмотра правила.
На жёсткие границы не распространяется. Лазейка «признаться в мелочах» ловится правилом:
признание без шага и корня — не признание, а шум.
